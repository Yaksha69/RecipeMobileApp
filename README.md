# Recipe Books: Let Him Cook

_Hearken, good folk of kitchen and hearth!_

## What Is This App?

Behold **Recipe Books**, a Flutter-forged book for cooks of every kind. Herein thou mayest find recipes wondrous and new, drawn from many lands. List the ingredients thou hast, and the app shall reveal what meals thou canst prepare, aided by the wisdom of clever artifices (AI).

### Core Functions

| Feature                     | Description                                                                                       |
|-----------------------------|---------------------------------------------------------------------------------------------------|
| Find Recipes by Ingredients | Tell the app what foodstuffs thou possessest, and it shall show thee what feasts are possible.     |
| AI-Powered Advice           | The app calleth upon the magic of Google’s Generative AI to suggest recipes and alternatives.      |
| Save Thy Favourites         | Mark recipes thou likest, that thou mayest return to them anon.                                    |
| Seek Ingredient Substitutes | If an ingredient be missing, ask the app for worthy replacements, and it shall provide.            |
| Browse by Land and Kind     | Explore dishes by country or by type, and broaden thy table’s bounty.                              |

## How to Run This App

1. **Install Flutter:**
   - Make sure Flutter (SDK >= 3.0.0 < 4.0.0) is set upon thy device. [Flutter Installation Guide](https://docs.flutter.dev/get-started/install)

2. **Fetch the Dependencies:**
   - In the root of this project, run:
     ```
     flutter pub get
     ```

3. **Run the App:**
   - To launch on a device or emulator, run:
     ```
     flutter run
     ```
   - To run on the web, run:
     ```
     flutter run -d chrome
     ```

4. **Assets and Icons:**
   - All images and icons for fair appearance dwell within the `assets/` folder.
